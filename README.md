# النظام — Solo Edition (v7.0)

مدرب عادات ومهام بطابع **النظام** من Solo Leveling — نسخة ويب + ويندوز + أندرويد.

الإصدار **7.0** يضيف هوية اللاعب والتحليلات ومهام البيزنس، ويحسّن السرعة والإشعارات:

- **حساب لاعب محلي:** تسجيل / دخول / استعادة كلمة مرور، واسم اللاعب المسجّل يظهر في كل شاشات النظام بدل الاسم المؤقت.
- **تحليلات اللاعب:** بطاقة داخل «الملف» + نافذة تفصيلية: XP أسبوعي، الالتزام، دقة العقل، السلسلة، التركيز، توزيع المهام، وخريطة 365 يومًا.
- **Business Mode:** مهام جديدة: Deep Work، Work Sprint، Make Money، Build Skill، Workout، Plan & Review — والمهام القديمة تُستبدل مرة واحدة عند الترقية.
- **وضع ليلي / نهاري:** زر في الهيدر + اختيار في الإعدادات، ويعمل مع كل الثيمات الـ22.
- **سرعة أعلى:** تخزين مؤقت لخريطة العقل وشبكة الخلفيات والثيمات، تقليل إعادة الرسم، إيقاف مؤقتات مكررة، صور خلفية مضغوطة، واحترام تقليل الحركة.
- **تواصل مع المطور:** قسم في آخر الإعدادات للشكاوى والاقتراحات + واتساب مباشر على `01008655235` مع رسالة جاهزة.
- **شاشة ترحيب جديدة:** الخلفية `9` + الرسالة المطلوبة **«لن تخرج من النظام كما دخلته»**.
- **إصلاح إشعارات أندرويد:** فحص إذن الإشعارات الأصلي عبر `SystemBridge`، وفتح إعدادات إشعارات التطبيق مباشرة، وإخفاء البانر المضلل لما تكون الخدمة مفعّلة. التوست انتقل للأسفل حتى لا يغطي البانر.
- **ترقية آمنة من 6.0:** XP والكريستالات والسجل والمكتبة والثيمات محفوظة. تُستبدل المهام فقط مرة واحدة.

## ★ الجديد في 7.0

### 1. تسجيل الدخول وهوية اللاعب
| البند | التفاصيل |
|---|---|
| إنشاء حساب | اسم اللاعب + البريد (اختياري) + كلمة مرور 6 خانات على الأقل |
| الدخول | باسم اللاعب أو البريد + كلمة المرور |
| التخزين | محلي بالكامل داخل المتصفح/الجهاز — لا سيرفر ولا إنترنت |
| كلمة المرور | تُخزّن كـ **هاش محلي** مع Salt، وليست نصًا صريحًا |
| تذكّرني | يبقي الجلسة مفتوحة على الجهاز؛ إلغاؤه يطلب الدخول في التشغيل التالي |
| اسم اللاعب | يظهر في الهيدر، الملف، البطاقة، الترحيب، والتحليلات، ويمكن تعديله من الملف/الإعدادات |
| استعادة الحساب | «نسيت كلمة المرور؟» تعيد تعيين كلمة المرور بعد مطابقة الاسم/البريد المحلي |
| ترقية من 6.0 | الحساب القديم يُرقّى تلقائيًا إلى حساب محلي مسجّل، بدون قفل المستخدم خارج بياناته |

> الحساب محلي وليس حسابًا سحابيًا. من يملك الجهاز يمكنه الوصول للبيانات؛ كلمة المرور بوابة استخدام وليست تشفيرًا للقرص.

### 2. التحليلات
- بطاقة **ANALYTICS** في تبويب «الملف» بملخص آخر 7 أيام.
- نافذة كاملة: XP وكريستالات الأسبوع، نسبة الالتزام، المهام المنجزة، دقة العقل، الاختبارات المحلولة، السلسلة، دقائق التركيز، وتوزيع مهام اليوم حسب التصنيف.
- رسم بياني أصلي بـ HTML/CSS بدون مكتبات خارجية.
- تُبنى الأرقام من `S.daily` وسجل المهام وبيانات العقل والتركيز.

### 3. المهام الجديدة (Business Mode)
- Deep Work — 90 دقيقة تركيز عميق (50 XP).
- Work Sprint — إنجاز مهمة العمل الأساسية (30).
- Make Money — 45 دقيقة دخل أو مشروع (30).
- Build Skill — تعلّم مهارة ترفع قيمتك (20).
- Workout — 30 دقيقة رياضة (20).
- Plan & Review — خطط للغد وراجع يومك (10).
- عند الترقية من 6.0 تُحذف المهام القديمة مرة واحدة فقط، ثم تُزرع مهام البيزنس. مهامك التي تضيفها بعد ذلك لا تُمسح.

### 4. الوضع الليلي والنهاري
- زر 🌙/☀️ في الهيدر + زرين في الإعدادات.
- يحافظ على الثيم المختار ويبدّل لوحة الألوان فقط.
- لوحة نهارية واضحة للنصوص والبطاقات والتحليلات وشاشة الدخول.

### 5. الخلفية والترحيب
- `9.jpg` هي خلفية التطبيق الافتراضية بعد ضغطها إلى `assets/bg9.jpg` (1600×900) لسرعة التحميل.
- `9 (2).jpg` متاحة كخلفية ثانية داخل المتجر/الخلفيات باسم «الجمجمة الحمراء».
- شاشة الترحيب 3D تعرض الرسالة: **«لن تخرج من النظام كما دخلته»**.

### 6. إشعارات أندرويد
- شاشة أندرويد لم تكن تدعم Web Notification، فكان البانر يقول «فعّل الإشعارات» بلا فائدة.
- أضيف إلى `SystemBridgePlugin`:
  - `notifStatus`: يقرأ `areNotificationsEnabled()` الحقيقي.
  - `openNotifSettings`: يفتح إعدادات إشعارات التطبيق مباشرة.
- عند نجاح الإذن يختفي البانر، ويظهر في الإعدادات «مفعّلة · خدمة النظام».
- زر «تفعيل الإشعارات» يفتح إعدادات النظام عند الرفض.
- التوست انتقل إلى أسفل الشاشة، فوق شريط التنقل، حتى لا يغطي بانر الإشعارات.

### 7. أساسيات الإصدارات السابقة (كلها تعمل)
- **IQ 365:** 365 اختبارًا يوميًا + 60 سؤال تدريب = **425 سؤالًا**، مع شرح، خريطة 365 يومًا، وسلسلة عقل.
- **22 ثيم أنمي** (Solo Leveling، Tokyo Ghoul، Attack on Titan، Demon Slayer…).
- **20 خلفية SVG** بدقة 8K + خلفيتان من المشروع + رفع خلفية خاصة.
- **شاشة ترحيب 3D** بمكعب Shadow Monarch وجزيئات.
- **إشعارات تفاعلية** + **6 حزم صوتية** WebAudio + **نظام 24/7**.
- XP دائمة منفصلة عن الكريستالات · رتب E→S · كويست يومي · منطقة عقاب · مهارات · ألقاب · صناديق · مفاتيح سرية · درع سلسلة · BOSS أسبوعي · تراجع 8 عمليات.

## تشغيل التطبيق

### الويب
افتح `index.html` بأي متصفح حديث. لا يحتاج إنترنت ولا تثبيت.
> أول تشغيل: أنشئ حساب لاعب. بعدها سيظهر اسمك في كل مكان.

### ويندوز
1. `تطبيق-ويندوز/النظام-7.0.0-Setup.exe` — مثبّت كامل (اختصار سطح المكتب + قائمة ابدأ).
2. `تطبيق-ويندوز/النظام-7.0.0-Portable.exe` — نسخة محمولة بدون تثبيت.

### أندرويد
1. انقل `تطبيق-أندرويد/النظام-7.0.apk` إلى الهاتف.
2. اسمح بالتثبيت من مصادر غير معروفة عند الطلب.
3. اسمح بالإشعارات عند أول تشغيل — ضرورية للخدمة الخلفية.
4. لو رفضت الإذن بالخطأ: الإعدادات → الإشعارات → زر «تفعيل الإشعارات» سيفتح إعدادات التطبيق.

## ⚠️ Smart App Control (ويندوز)
ملفات `.exe` غير موقّعة رقميًا، وقد يمنعها **Smart App Control**:

**Windows Security → App & browser control → Smart App Control → Off → Restart**

أو استخدم نسخة الويب أو أندرويد، وكلاهما يعمل بدون أي قيود.
التفاصيل في `تطبيق-ويندوز/طريقة-التثبيت.md`.

## إعادة البناء

### ويندوز
```
copy index.html C:\zbuild\win\index.html
copy assets\bg9.jpg C:\zbuild\win\assets\bg9.jpg
copy assets\bg9b.jpg C:\zbuild\win\assets\bg9b.jpg
cd C:\zbuild\win
$env:EB_UNINSTALLER_READER='1'
npx electron-builder --win nsis portable --x64
```
النواتج في `C:\zbuild\win\dist`، ثم انسخها إلى `تطبيق-ويندوز` وأعد تسميتها إلى `النظام-7.0.0-Setup.exe` و`النظام-7.0.0-Portable.exe`.

> `EB_UNINSTALLER_READER=1` مطلوب بسبب تعديل محلي في `app-builder-lib` على هذا الجهاز.

### أندرويد
```
copy index.html C:\zbuild\android\www\index.html
mkdir C:\zbuild\android\www\assets
copy assets\bg9.jpg C:\zbuild\android\www\assets\bg9.jpg
copy assets\bg9b.jpg C:\zbuild\android\www\assets\bg9b.jpg
cd C:\zbuild\android
npx cap copy android
cd android
.\gradlew.bat assembleRelease
```
الناتج: `C:\zbuild\android\android\app\build\outputs\apk\release\app-release.apk`.

- `versionName 7.0` · `versionCode 7` · `applicationId com.gamify.rewards` · `minSdk 24`.
- التوقيع: `rewards.keystore` — كلمة السر وalias محفوظان privately (لا يُنشران في المستودع) — alias `rewards`.
- **احتفظ بملف التوقيع** لتحديثات مستقبلية بنفس الهوية.
